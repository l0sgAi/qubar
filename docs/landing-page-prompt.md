## 页面内容底稿

### 1. Hero 区

- 徽章：`Go · DDD · 模块化单体`
- 大标题：`让同好相聚，让热爱发生`（其中「热爱」位做关键词轮播：热爱 / 灵感 / 兴趣 / 同好）
- 一句话简介：`Qubar 是一个基于 Go 与 DDD 领域驱动设计的现代化兴趣社区平台——圈子、帖子、评论、点赞之外，内置 AI 社区机器人、实时消息推送与三路个性化信息流。`
- CTA：`GitHub 仓库`（https://github.com/l0sgAi/qubar）、`了解功能 ↓`
- 数据指标（滚动计数）：
  - `15` 个自治业务领域
  - `4` 种登录方式
  - `3` 路信息流引擎
  - `6` 大基础设施中间件

### 2. 核心功能（6 卡片）

| 卡片 | 标题 | 文案 |
|---|---|---|
| 1 | 兴趣圈子 | 创建与加入主题圈子，圈主 / 管理员 / 成员三级 RBAC 权限：禁言、封禁、审核、转让、角色任免一应俱全；支持圈子分类、随机逛圈与活跃榜。 |
| 2 | 内容创作 | 图文帖子 + 图片 / 视频多媒体上传（S3 预签名直传），帖子按圈子聚合，支持「我的帖子」「TA 的帖子」与关键词检索。 |
| 3 | 评论互动 | 二级扁平化评论结构，root_id 标记层级、避免递归查询；支持回复、评论点赞、@ 提及其他用户并精确落库。 |
| 4 | 全文搜索 | Elasticsearch 8 支撑用户 / 圈子 / 帖子三类搜索，数据经 CDC 实时同步进 ES；ES 不可用时自动降级为数据库检索。 |
| 5 | AI 社区机器人 | 平台级与圈子级两级机器人：关键词触发、发帖 @ 触发、手动触发三种模式，基于 eino 编排接入 OpenAI / Claude，圈内机器人每圈最多 5 个、独立人设与权限矩阵。 |
| 6 | 实时消息中心 | 点赞、评论、回复、@ 提及实时扇出为通知，Redpanda 消息流驱动；SSE 长连接把未读数毫秒级推到前端，支持一键已读。 |

### 3. AI 社区机器人（深挖区块）

- 标题：`会接梗的社区，有 AI 常驻`
- 要点列表：
  - 三种触发方式：评论命中关键词、发帖 @ 机器人、圈主 / 管理员手动指定回复
  - 两级作用域：平台全局机器人 + 圈内专属机器人（每圈 ≤ 5 个），人设、提示词、凭据各自独立
  - 权限分级：凭据修改与删除仅圈主，触发回复圈内 admin+，全局机器人仅超管
  - 基于 eino 的 LLM 编排，已接入 OpenAI / Claude，回复自动带上帖子上下文摘要
- 拟物视觉：聊天窗口（用户 `@小Q 求推荐 Go 微服务的学习路线` → 打字中动画 → 机器人回答）。

### 4. 实时消息与互动（深挖区块）

- 标题：`每一次互动，都能被即时感知`
- 要点列表：
  - 点赞 / 收藏 / 评论 / 回复 / @ 提及 → Redpanda 事件流 → 通知扇出落库
  - SSE 长连接实时推送未读数，与 `GET /notice/unread-count` 同源数据，多标签页自动同步
  - 点赞统计 Write-Behind：Redis 实时更新 + Redpanda 批量落库，高并发下不丢计数
  - 浏览历史、收藏夹、点赞列表随时回看
- 拟物视觉：通知面板，铃铛角标脉动递增，通知条目（回复 / 点赞 / @ 提及）逐条滑入。

### 5. 信息流三引擎（深挖区块）

- 标题：`三种方式，遇见好内容`
- 三个 Tab：
  - **推荐**：基于已加入圈子与浏览种子的个性化召回，ES 检索 + 结果缓存，越用越懂你
  - **热门**：热度榜单，互动数据实时加权，全站与圈内双维度
  - **发现**：反信息茧房随机池，登录后按行为去重，匿名也能逛
- 拟物视觉：带 Tab 的信息流面板，迷你帖子卡片（标题 + 圈子标签 + 互动数）。

### 6. 架构亮点

- 分层视觉：`编排层 composition` → `15 个自治领域 domains` → `共享内核 shared` → `基础设施（PG / Redis / ES / Redpanda / S3 / Nacos）`
- 4 条关键设计决策：
  1. **UUIDv7 主键**：前 48 位时间戳，字典序 = 时间序，天然支持 keyset 游标分页
  2. **跨领域 Facade**：领域间只通过接口调用，模块化单体可随时平滑拆分微服务
  3. **框架无关路由**：领域代码不依赖 HTTP 框架，Hertz 仅作适配层
  4. **Write-Behind 统计**：Redis 实时 + Redpanda 异步批量落库，扛住高并发互动

### 7. 技术栈

- marquee 词条：`Go 1.25` `Hertz` `GORM` `Sa-Token` `Viper` `Zap` `PostgreSQL 18` `Redis 7` `Elasticsearch 8` `Redpanda` `AWS S3` `Nacos` `eino` `UUIDv7` `SSE`
- 分组网格：
  - 语言与框架：Go 1.25 / Hertz / GORM / Sa-Token / Viper / Zap
  - 数据存储：PostgreSQL 18（UUIDv7 + JSONB）/ Redis 7（Lua 原子操作）
  - 消息与搜索：Redpanda（Kafka 兼容）/ Elasticsearch 8
  - 平台设施：AWS S3 预签名 / Nacos 配置中心 / eino LLM 编排

### 8. 结尾

- CTA：`开源 · 可自建 · 欢迎 Star` → GitHub 按钮
- 页脚：`Qubar — 让同好相聚` · License 见仓库 · Built with Go

## 功能事实清单（实现口径，禁止超出此范围宣传）

以下为后端**已实现**的功能，全部可在仓库代码中验证（`pkg/domains/`，共 15 个领域）：

- **auth**：邮箱注册（验证码两步）、登录 / 登出、密码重置（验证码）；OAuth 登录：Google / GitHub / Azure AD；Sa-Token 会话。
- **user**：资料查询 / 更新、用户搜索、用户详情。
- **category**：圈子分类列表。
- **circle**：创建 / 更新圈子、圈子列表 / 详情 / 我加入的 / TA 加入的 / 活跃榜 / 随机逛圈、成员列表、圈内帖子；管理操作：审核、禁言 / 解禁、封禁 / 解封、角色任免、转让圈主、可管理圈子列表（含圈内机器人数量回填）。
- **post**：发帖（图文 + 媒体）、帖子列表（关键词搜索、keyset 分页）、详情、我的帖子、用户帖子；发帖 @ 提及精确绑定落库并在响应中回传。
- **comment**：二级扁平化评论（root_id）、发表评论（支持 @ 提及）、评论列表 / 回复列表 / 详情。
- **like**：帖子 / 评论点赞切换（Redis 原子 + 事件流）。
- **collect**：收藏切换、我的收藏列表。
- **history**：浏览历史记录与列表。
- **notice**：通知列表、未读数、单条 / 全部已读；SSE `/notice/stream` 未读数实时推流（Redpanda flush 触发、多标签页同步）。
- **recommend**：首页个性化推荐 Feed（ES 召回 + 缓存）。
- **trending**：热门榜单。
- **discover**：反气泡发现池（匿名可访问，登录后个性化去重）。
- **aiagent**：平台级机器人 CRUD + 手动触发回复（超管）；圈子级机器人 CRUD（admin+，每圈 ≤ 5，凭据 / 删除仅圈主）+ 圈主手动触发；自动触发：评论关键词命中、发帖 @ 机器人；LLM 走 eino（OpenAI / Claude）。
- **storage**：图片 / 视频上传、S3 预签名 URL、文件删除。

技术事实：Go 1.25 · Hertz v0.10 · PostgreSQL 18（UUIDv7 主键）· Redis 7 · Elasticsearch 8 · Redpanda · AWS S3 · Nacos · Mailtrap 邮件 · eino LLM 编排 · DDD 模块化单体（composition / domains / shared 四层）。
